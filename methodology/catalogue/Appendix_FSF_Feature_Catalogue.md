# Appendix: Literature-backed predictor catalogue

## Selection protocol

The catalogue does not impose a predetermined number of predictors. It preserves complete named specifications, complete Vietnam benchmark blocks, published raw-accounting universes, PU label-mechanism variables, and block-level recent extensions. The pre/post-audit contribution is generated by an ex ante rule applied to every eligible accounting item rather than by selecting ten convenient accounts.

| Tier | Rule | Anti-cherry-picking safeguard |
|---|---|---|
| C1 | Include the complete named published specification when mapping and timing are valid. | No component screening using Vietnamese outcomes. |
| C2 | Replicate the complete prespecified candidate/control block. | Do not retain only significant variables from the original studies. |
| C3/C4 | Use complete blocks or all concepts meeting ex ante mapping, authorization, coverage and nonredundancy rules. | No predetermined feature count and no outcome-based ranking. |
| C5 | Model or audit P(observed positive \| latent positive) separately. | Separate content-only, label-mechanism-only, full and source-blind views. |
| R1/R2 | Evaluate as complete blocks in robustness analyses. | Do not promote top SHAP/ANOVA/PCA features into confirmatory analysis. |
| N1 | Apply identical transformations to every eligible authorized accounting item. | No hand-picked ten-item set; target-component ablations are mandatory. |
| BLOCK | Exclude from all predictor matrices. | Prevents serial-firm memorization and look-ahead bias. |
